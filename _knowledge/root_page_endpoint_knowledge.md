# root_page_endpoint_knowledge

root_page_endpoint_task 수행에 필요한 지식:

- 계약: `GET /` → 웹페이지(index.html) 제공 (원문 엔드포인트 요약표 L19–27).
- 제공물: 상품(바나나, 우유) 전시와 결제를 처리하는 웹페이지 — API와 한 서버가 함께 제공.
- 환경: Node.js 22 · Express 5; Base URL 배포 `http://52.79.242.131` / 로컬 `http://localhost:3000`.
- 이 엔드포인트만 HTML을 반환하며, 나머지 세 엔드포인트는 JSON을 반환한다.
