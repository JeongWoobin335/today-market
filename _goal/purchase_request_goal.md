# purchase_request_goal

PURCHASE_REQUEST 정체성에서 유도한 목표: 모든 구매 시도가 4개 필수 파라미터
(productName·quantity·amount·walletAddress)를 완비한 단일 고정 형태로만 서버에
도달하여, 후속 검증·처리가 형태 불확실성 없이 동일한 입력 계약 위에서 동작하는
상태를 이룬다.
