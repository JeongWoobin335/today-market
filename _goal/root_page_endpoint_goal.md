# root_page_endpoint_goal

ROOT_PAGE_ENDPOINT 정체성에서 유도한 목표: 사용자가 서버 루트(`GET /`)에
접근하면 언제나 상품 전시·결제 UI(index.html)가 제공되어, 웹페이지와 API가
하나의 Node.js(Express) 서버에서 함께 서비스되는 상태를 이룬다.
