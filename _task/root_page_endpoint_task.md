# root_page_endpoint_task

root_page_endpoint_goal 달성을 위해 수행할 작업:

1. `GET /` 라우트를 서버에 등록한다.
2. 요청 수신 시 index.html(상품 전시·결제 UI)을 응답으로 제공한다.
3. 웹페이지가 같은 서버의 API(`GET /products`, `POST /purchase`)를 호출할 수 있도록 동일 오리진 제공을 유지한다.
